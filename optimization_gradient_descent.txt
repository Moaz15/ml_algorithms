
1. CORE FOUNDATIONS & MATHEMATICS
--------------------------------------------------------------------------------
* Definition: An iterative optimization algorithm used to minimize a cost 
  function J(theta) by updating parameters in the direction of steepest descent.

* The Update Rule:
  theta := theta - alpha * grad_J(theta)
  
  - theta: Model weights/biases.
  - alpha: Learning rate (step size).
  - grad_J(theta): Gradient vector (partial derivatives of J with respect to 
    each parameter).

* Mathematical Guarantee: 
  By first-order Taylor Series approximation, moving in the direction of the 
  negative gradient ensures the dot product of your step and the gradient is 
  strictly negative:
  -alpha * ||grad_J(theta)||^2 < 0
  
  This mathematically guarantees a local decrease in loss for a sufficiently 
  small alpha.

3. SCALE-UP DYNAMICS & DISTRIBUTED TRAINING
--------------------------------------------------------------------------------
When scaling models to billions of parameters across hundreds of GPUs, distributed 
paradigms are required:

* Data Parallelism (DP): 
  The model fits on one GPU. The large mini-batch is split across GPUs. Each 
  calculates local gradients; an All-Reduce network operation averages them 
  across all devices before updating.

* Model Parallelism (MP): 
  The model is too big for a single GPU's memory.
  - Tensor Parallelism: Slices weight matrices within a layer across multiple 
    GPUs (requires ultra-fast NVLink).
  - Pipeline Parallelism: Slices sequential layers across multiple GPUs (uses 
    1F1B scheduling to reduce idle "bubbles").

* The Large-Batch Phenomenon: 
  Scaling batch sizes drastically (e.g., 256 to 32,768) causes a "generalization 
  gap" because the gradient becomes too smooth, trapping the model in sharp, 
  poor local minima.
  - Fix 1 (Linear Scaling Rule): If batch size increases by factor k, multiply 
    alpha by k.
  - Fix 2 (Learning Rate Warmup): Linearly ramp up alpha from 0 to the target 
    rate over the first few epochs to avoid initial divergence.
  - Fix 3 (Adaptive Layer Optimizers): Use LARS (for CNNs) or LAMB (for 
    Transformers) to scale learning rates per layer dynamically.


Q1: What happens if the learning rate (alpha) is too high or too low?
A1: - Too High: The step size overshoots the minimum, violating the Taylor 
      expansion assumption. It causes the loss to oscillate or diverge completely 
      (resulting in NaN).
    - Too Low: The algorithm takes minuscule steps, leading to painfully slow 
      convergence and a high risk of getting trapped in a shallow local minimum 
      or saddle point.

Q2: Why do we shuffle the dataset before creating mini-batches?
A2: Shuffling breaks any inherent order or bias in the data sequence. Without it 
    (e.g., if all positive class samples appear first), successive mini-batch 
    updates will pull weights in contradictory directions, leading to extreme 
    cyclic oscillations and poor convergence.

Q3: Why does SGD struggle with saddle points, and how do modern variants fix it?
A3: At a saddle point, the gradient is zero or near-zero along all axes, causing 
    vanilla SGD to completely stall. Modern algorithms fix this by adding 
    Momentum (incorporating past velocity to roll through flat regions) or using 
    adaptive learning rates like Adam (scaling updates based on past gradient 
    variance).

Q4: Explain the difference between a Local Minimum and a Saddle Point.
A4: - At a Local Minimum, the gradient is zero, and all surrounding directions 
      point upward (all eigenvalues of the Hessian matrix are positive). 
    - At a Saddle Point, the gradient is also zero, but some directions point up 
      while others point down (the Hessian has both positive and negative 
      eigenvalues). Saddle points are far more common in high-dimensional deep 
      learning landscapes.

Q5: How do L1 and L2 regularization affect the Gradient Descent update step 
    mathematically?
A5: - L2 Regularization (Weight Decay): Adds (lambda/2)*||theta||^2 to the loss. 
      Its gradient is (lambda * theta). The update step becomes:
      theta := theta * (1 - alpha * lambda) - alpha * grad_J_original(theta)
      This continuously shrinks weights toward zero proportionally to their size.
      
    - L1 Regularization: Adds lambda*||theta||_1 to the loss. Its gradient is 
      lambda * sign(theta). The update step becomes:
      theta := theta - alpha * grad_J_original(theta) - alpha * lambda * sign(theta)
      This subtracts a constant value regardless of weight magnitude, driving 
      less important weights exactly to absolute 0, yielding model sparsity.
