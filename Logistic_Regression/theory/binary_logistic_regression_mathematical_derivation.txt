Binary Logistic Regression — Complete Derivation

Problem Statement

1. We are solving a binary classification problem.

Given:
Input features:
x = (x1, x2, ..., xn), x ∈ R^n
Output label:
y ∈ {0, 1}

Examples:
Will a user click or not click?
Is an email spam or not spam?

2. What Is the Goal?

Our goal is NOT just to predict a class (0 or 1).
Our real goal is to predict a probability:  P(y = 1 | x)

Decision rule:
If predicted probability >= 0.5 → predict class 1
Else → predict class 0

3. Linear Model (Starting Point)

We first compute a linear score:
z = θ^T x + b
Where:
θ = weights (to be learned)
b = bias term

Problem:
z can take any real value (-∞ to +∞)
Probabilities must lie between 0 and 1

4. Mapping Scores to Probabilities (Sigmoid Function)

To convert z into a probability, we use the sigmoid function:
σ(z) = 1 / (1 + e^(-z))

Properties:
Output is always between 0 and 1
Large positive z → probability close to 1
Large negative z → probability close to 0
sigmoid is always a monotonic function

Why Sigmoid Must Be Monotonic

Definition:
A monotonic function is one that is either entirely non-increasing or non-decreasing.
The sigmoid function used in logistic regression is strictly increasing:
σ(z) = 1 / (1 + e^(−z))

Benefits of Monotonicity:
1. Rank Preservation: More positive z → higher probability
2. Predictable Thresholding: Thresholds like 0.5 work reliably
3. Smooth Optimization: Gradient always positive, aiding convergence
4. Interpretability: Higher distance → higher probability for class 1



5. Logistic Regression Hypothesis Function

The model prediction is:
ŷ = P(y = 1 | x) = σ(θ^T x + b)
Also:
P(y = 0 | x) = 1 - ŷ

6. How Do We Measure Prediction Error?

Since the model predicts probabilities, we need a loss function that:
1.Penalizes confident wrong predictions
2.Works naturally with probabilities

7. Binary Cross-Entropy Loss (Single Example)

Loss for one training example:
L(ŷ, y) = - [ y * log(ŷ) + (1 - y) * log(1 - ŷ) ]
Intuition:
If y = 1 and ŷ is small → large loss
If y = 0 and ŷ is large → large loss

Correct and confident predictions → small loss

8. Loss Over the Entire Dataset

For m training examples:
J(θ, b) = -(1 / m) * Σ [ yi * log(ŷi) + (1 - yi) * log(1 - ŷi) ]

This is the objective function we want to minimize.

9. WHY DOES THIS LOSS FUNCTION MAKE SENSE?

Thinking in Terms of Probabilities
For each input x, the model predicts:
ŷ = P(y = 1 | x)

A good model should:
Assign high probability to what actually happened
Assign low probability to incorrect outcomes

Probability of One Data Point

If y = 1:  P(y | x) = ŷ
If y = 0:  P(y | x) = 1 - ŷ

This can be written compactly as :
P(y | x) = ŷ^y * (1 - ŷ)^(1 - y)

Probability of the Entire Dataset

Assuming all data points are independent:
P(data) = Π [ ŷi^yi * (1 - ŷi)^(1 - yi) ]
This quantity is called the likelihood.

Maximum Likelihood Estimation (MLE) means:
Choose parameters (θ, b) such that the observed data becomes as probable as possible under the model.

Why Do We Take the Log?

Reasons:
Converts products into sums
Easier to optimize
Does not change the optimal solution 

log P(data) = Σ [ yi * log(ŷi) + (1 - yi) * log(1 - ŷi) ]

From Likelihood to Loss Function

Machine learning algorithms minimize loss.
So we take the negative average log-likelihood:   Loss = - (1 / m) * log P(data)
This gives the Binary Cross-Entropy Loss used earlier.

10. What Are We Learning?

We learn:
Weights (θ): importance of each feature
Bias (b): baseline tendency toward class 1
Decision boundary:
θ^T x + b = 0

11. Learning the Parameters (Gradient Descent)

Now that we have the objective function, we need a way to find the values of θ and b that minimize it.
We use Gradient Descent, an iterative optimization algorithm.

11.1 Why Do We Need Gradients?

The loss function depends on the parameters through the following chain:
θ, b → z = θᵀx + b → ŷ = σ(z) → Loss

To minimize the loss, we compute how the loss changes when θ and b change slightly.
This is done using derivatives (gradients).

11.2 Loss for One Training Example

Loss for a single example i:  Li = - [ yi * log(ŷi) + (1 - yi) * log(1 - ŷi) ]
where:
ŷi = σ(zi)
zi = θᵀxi + b

11.3 Applying the Chain Rule

θ affects the loss indirectly: θ → zi → ŷi → Li

Using the chain rule:
∂Li / ∂θ = (∂Li / ∂ŷi) * (∂ŷi / ∂zi) * (∂zi / ∂θ)

11.4 Key Result: Error Term

After differentiating and simplifying, the derivative of the loss with respect to zi becomes:
∂Li / ∂zi = ŷi - yi
This quantity appears repeatedly, so we define:
error_i = ŷi - yi

This error term is not assumed — it naturally emerges from the mathematics.

11.5 Gradients for One Training Example

Using zi = θᵀxi + b:

Gradient with respect to weights:
∂Li / ∂θ = (ŷi - yi) * xi

Gradient with respect to bias:
∂Li / ∂b = (ŷi - yi)

11.6 Gradients Over the Entire Dataset

Averaging over all m training examples:

Gradient with respect to weights:
∂J / ∂θ = (1 / m) * Σ (ŷi - yi) * xi

In vectorized form:
∂J / ∂θ = (1 / m) * Xᵀ (ŷ - y)

Gradient with respect to bias:
∂J / ∂b = (1 / m) * Σ (ŷi - yi)


12. Parameter Update Rules

θ := θ - α * (1 / m) * X^T (ŷ - y)
b := b - α * (1 / m) * Σ (ŷ - y)

α is the learning rate

These updates are repeated until the loss converges.

Why no Closed-Form Solution?

Does NOT exist for Logistic Regression
Loss function is non-linear
No analytical minimum

13. Summary

Logistic Regression predicts probabilities
Sigmoid maps linear scores to probabilities
Cross-entropy measures probability mismatch
MLE explains why this loss is correct
Gradient descent learns optimal parameters
