Binary Logistic Regression — Complete Derivation

Problem Statement
1. We solve a binary classification problem where we map input features to a discrete label.

Given:
Input features:
x = (x1, x2, ..., xn), x ∈ R^n
Output label:
y ∈ {0, 1}

Examples:
Will a user click or not click?
Is an email spam or not spam?

2. What Is the Goal?

Our goal is NOT just to predict a class (0 or 1).
Our real goal is to predict a conditional probability:  P(y = 1 | x)

Decision rule:
If predicted probability >= 0.5 → predict class 1
Else → predict class 0

3. Linear Model (Starting Point)

We first compute a linear score:
z = θ^T x + b
Where:
θ = weights (to be learned)
b = bias term

Problem:
z can take any real value (-∞ to +∞)
Probabilities must lie between 0 and 1

4. The Activation (Sigmoid Function)
Mapping Scores to Probabilities
To convert z into a probability, we use the sigmoid function:
               ŷ =  σ(z) = 1 / (1 + e^(-z))

Why Sigmoid?
------------------------------------------------------------------------------------------------------------------------
1. Output Range:
   Maps any real number to (0, 1)

2. Differentiability:
   It has a very "clean" derivative: σ'(z) = σ(z)(1 - σ(z)).
   This is crucial for gradient descent.

3. Monotonicity:
   Ensures that an increase in the score z always results in an increase (or equality) in the probability ŷ.

------------------------------------------------------------------------------------------------------------------------

4. The Likelihood Function (MLE)

We don't just "pick" the loss function; 
we derive it using Maximum Likelihood Estimation.

For a single point, the probability of observing label y is:
P(y|x) = ŷ^y (1-ŷ)^(1-y)

For a dataset of m independent examples, the Likelihood is the product:
L(θ, b) = ∏_{i=1}^{m} ŷ_i^{y_i} (1-ŷ_i)^(1-y_i)

5. Cost Function: Binary Cross-Entropy (BCE)

Maximizing the likelihood is mathematically equivalent to minimizing the Negative Log-Likelihood (NLL). Taking the log turns products into sums and makes the math easier:
J(θ, b) = -1/m ln L(θ, b)
J(θ, b) = -1/m ∑_{i=1}^{m} [y_i log(ŷ_i) + (1 - y_i) log(1 - ŷ_i)]

Interviewer Note: This function is convex, meaning gradient descent is guaranteed to find the global minimum.

6. Optimization: Gradient Descent

We minimize J(θ, b) by updating parameters in the opposite direction of the gradient.

The Chain Rule Derivation

For one example, the gradient w.r.t a weight θ is:
∂L/∂θ = ∂L/∂ŷ ⋅ ∂ŷ/∂z ⋅ ∂z/∂θ
Loss derivative: ∂L/∂ŷ = -y/ŷ + (1-y)/(1-ŷ) = (ŷ-y)/(ŷ(1-ŷ))

Sigmoid derivative: ∂ŷ/∂z = ŷ(1-ŷ)

Score derivative: ∂z/∂θ = xj

Multiplying these:
∂L/∂θ = (ŷ - y)xj

7. Parameter Update Rules

After averaging over all m examples, the update rules (with learning rate α) are:
θ := θ - α (1/m) X^T (ŷ - y)
b := b - α (1/m) ∑ (ŷ - y)

Key "Interview Gold" Additions (Updates)

Why no Closed-Form solution? Unlike Linear Regression (where we use the Normal Equation (X^TX)^-1 X^Ty), the derivative of the Logistic Loss leads to a transcendental equation (it has both linear and exponential terms). You cannot isolate θ algebraically; hence, we use iterative methods like Gradient Descent or Newton’s Method.
The Decision Boundary: Note that the decision boundary is where ŷ = 0.5, which happens when θ^T x + b = 0. This confirms that Logistic Regression is a Linear Classifier, even though it uses a non-linear sigmoid function.
Assumptions: Mention that we assume observations are Independent and Identically Distributed (I.I.D.) and that there is little to no multicollinearity among features.


"Going Downhill"
"We move in the opposite direction of the gradient because the gradient represents the direction of the steepest increase in the loss function. 
By subtracting the gradient from our parameters, we take a step in the direction of the steepest decrease. 
This iterative process allows us to navigate the loss surface until we converge at a global or local minimum where the error is minimized."

"how the 'Learning Rate' (alpha) affects this 'downhill' journey" ?

The Learning Rate (alpha): 
Choosing Your Step Size
In the update rule theta := theta - alpha * gradientJ, the learning rate acts as a scaling factor. 
Since the gradient only gives us the direction, alpha determines how far we travel in that direction.

1. If alpha is too small (The Snail)
Behavior: You take tiny, microscopic steps.
Result: Training is incredibly slow. It might take hours or days to reach the minimum, or the model might get stuck in a "flat" region (plateau) of the loss surface before it ever reaches the bottom.

2. If alpha is too large (The Overshooter)
Behavior: You take massive leaps.
Result: You might step right over the valley and land on the other side, potentially even higher than where you started. This causes the loss to diverge (get larger and larger) rather than converge. The model "explodes" and never finds the minimum.

3. If alpha is just right (The Goldilocks)
Behavior: You take efficient steps that get smaller as the gradient gets shallower.
Result: You reach the minimum quickly and settle there smoothly.
