------------------------------------------------------------------------------------------------------------------------------------------------
Confusion Matrix                         
                                        Predicted
                                 | Positive (1) | Negative (0) |
            | ------------------ | ------------ | ------------ |
Actual      | Positive (1)       | TP           | FN           |
            | Negative (0)       | FP           | TN           |

second word - what the model predicted 
first word  - what the model predicted was correct or not

FP = false alarm
FN = missed detection

------------------------------------------------------------------------------------------------------------------------------------------------
Accuracy :
Accuracy measures how many predictions the model got right overall :  “Out of all predictions, how many were correct?”

Formula : Accuracy = (TP + TN) / (TP + TN + FP + FN)
Accuracy = Correct predictions / Total predictions

When Accuracy Is Useful
Dataset is balanced
Cost of FP and FN is similar
Example: Simple exam pass/fail classification

When Accuracy Is Misleading
Dataset is imbalanced
Example: 95% users do not churn
Model predicts “no churn” for everyone
Accuracy = 95% (but model is useless)

Accuracy
Does not tell what kind of mistakes are made : False Positives or False Negatives
Which type of error is happening more?
Ignores class imbalance

Accuracy tells how many predictions are right, not how the model is wrong.

------------------------------------------------------------------------------------------------------------------------------------------------
Precision : 

Precision measures how many predicted positives are actually correct.
“When the model says Positive, how often is it right?”
Precision = TP / (TP + FP)

Precision = Correct Positives / All Predicted Positives
Focus only on predicted positives.

Precision cares about False Positives.
High precision means:
Few false alarms
Model is careful when predicting positive

Use Precision when False Positives are costly.

Examples:

Spam detection
FP → important email goes to spam
Recommendation notifications
FP → user gets irrelevant notifications

Precision tells how trustworthy a positive prediction is.
Precision alone does not tell:
How many positives the model missed

-----------------------------------------------------------------------------------------------------------------------------------------------
Recall (Sensitivity / True Positive Rate)

Recall measures how many actual positives the model correctly identified.
“Out of all the real positives, how many did the model catch?”

Recall = TP / (TP + FN)
Recall = Caught Positives / All Actual Positives

Recall cares about False Negatives.
High recall means:
Few missed positives
Model rarely says “No” when it should say “Yes”

Use Recall when False Negatives are costly.

Medical diagnosis
FN → disease goes undetected
Fraud detection
FN → fraud transaction allowed

Recall alone does not tell:
How many false alarms the model makes


-----------------------------------------------------------------------------------------------------------------------------------------------

F1 Score : 
F1 Score measures the balance between Precision and Recall.

“Is the model both accurate when it predicts positive and good at finding positives?”

Why Do We Need F1 Score?
Precision and Recall often trade off:
Increasing Precision ↓ Recall
Increasing Recall ↓ Precision
F1 Score combines both into one number.


F1 = 2 × (Precision × Recall) / (Precision + Recall)
It is the harmonic mean, not the average.

F1 is high only if both Precision and Recall are high.
If either is low → F1 drops sharply.

Use F1 when:
Dataset is imbalanced
Both FP and FN matter
You want a single metric to compare models

What F1 Score Ignores
True Negatives (TN)
Probability calibration
So F1 is not ideal when:
Negative class is important

F1 Score tells how well the model balances missing positives and raising false alarms.

-----------------------------------------------------------------------------------------------------------------------------------------------

Specificity (True Negative Rate)

Specificity measures how well the model correctly identifies negative cases.
“Out of all actual negatives, how many did the model correctly predict as negative?”

Specificity = TN / (TN + FP)
Where:
TN = True Negatives
FP = False Positives

Specificity = Correct Negatives / All Actual Negatives

Focus only on actual negatives.
Specificity cares about False Positives.

High specificity means:
Few false alarms
Model is good at saying “No” when it should

Use Specificity when False Positives are costly.
