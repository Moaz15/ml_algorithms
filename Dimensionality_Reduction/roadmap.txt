2. LINEAR METHODS                                             -> linear_dr.txt
--------------------------------------------------------------------------------
[ ] 2.1 PCA (Principal Component Analysis)
        Theory
        - Directions of maximum variance; components are orthogonal
        - Covariance matrix -> eigenvectors (directions) + eigenvalues (variance)
        - Equivalent view: minimizing reconstruction error
        Practical
        - Explained variance ratio and cumulative variance
        - Scree plot / elbow to choose k; or "keep 95% variance"
        - Inverse transform for reconstruction and denoising
        - Interpreting component loadings
        Gotchas
        - Must scale features first
        - Unsupervised: max-variance direction may not be the discriminative one
        - Sensitive to outliers
[ ] 2.2 SVD (Singular Value Decomposition)
        - A = U S V^T; relationship to PCA (SVD on centered data)
        - Truncated SVD: the go-to for sparse matrices (TF-IDF, count data)
        - LSA: Truncated SVD applied to text for latent topics
[ ] 2.3 LDA (Linear Discriminant Analysis)
        - Supervised: uses class labels, unlike PCA
        - Within-class vs. between-class scatter; maximize separability
        - Hard cap: at most (num_classes - 1) components
        - PCA vs. LDA: when each wins
[ ] 2.4 Random Projection
        - Johnson-Lindenstrauss idea: random directions roughly preserve distances
        - Extremely cheap; useful when d is huge and PCA is too slow

3. NON-LINEAR METHODS (MANIFOLD LEARNING)                 -> non_linear_dr.txt
--------------------------------------------------------------------------------
[ ] 3.1 Manifold Hypothesis
        - Real data lies on a low-dimensional manifold inside high-d space
        - Why a straight linear projection can flatten out real structure
[ ] 3.2 Kernel PCA
        - PCA in an implicit feature space via the kernel trick
        - Kernels: RBF, polynomial, sigmoid; tuning gamma
        - Cost: O(n^2) in samples -> does not scale to large n
[ ] 3.3 t-SNE
        - Preserves local neighborhoods; KL-divergence objective
        - Perplexity: the main knob (typical 5-50)
        - Visualization only: no reusable transform, distances/cluster sizes and
          inter-cluster gaps are not meaningful
        - Practice: run PCA to ~50 dims first, then t-SNE
[ ] 3.4 UMAP
        - Preserves local + more global structure; much faster than t-SNE
        - Knobs: n_neighbors (local vs. global), min_dist (cluster tightness)
        - Has a reusable transform -> can feed downstream models
        - UMAP vs. t-SNE: default to UMAP in practice
[ ] 3.5 Autoencoders
        - Encoder -> bottleneck -> decoder; trained to reconstruct the input
        - The bottleneck activations are the learned low-dim representation
        - Non-linear generalization of PCA (a linear autoencoder ~ PCA)
        - Use when: large data, images/text, DR must live inside a NN pipeline

        - Labels available, classifier  -> LDA
        - Visualization / EDA           -> UMAP (t-SNE as backup)
        - Huge d, need it cheap         -> Random Projection
        - Deep pipelin˝e, lots of data   -> Autoencoder
        - Need interpretable features   -> Feature selection, not extraction
