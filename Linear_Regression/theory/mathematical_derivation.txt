LINEAR REGRESSION — MATHEMATICAL DERIVATION
===========================================

PART 0 — NOTATION AND KEY RESULTS
==============================================================================

    n            observations              d            features
    X ∈ ℝ^(n×d)  design matrix             y ∈ ℝ^n      targets
    β ∈ ℝ^d      coefficients              ŷ = Xβ̂       predictions

Intercept: append a column of ones to X, so β₀ is just another coefficient (the
"bias trick"). Assumed throughout, which is why no derivation below needs a
separate ∂/∂β₀ step.

Model (assumed):     y = Xβ + ε,   ε ~ (0, σ²I)
Fit (computed):      ŷ = Xβ̂

Error vs residual — different things:
    error     εᵢ = yᵢ - xᵢᵀβ    true β, unobservable
    residual  eᵢ = yᵢ - xᵢᵀβ̂    estimated β̂, computable

"Linear" means linear in the PARAMETERS. ŷ = β₀ + β₁x + β₂x² is linear
regression (put x² in as a column). 
ŷ = β₀ + x^β₁ is not.

Everything derived below, in one place:

    Objective        SSE(β) = ||y - Xβ||²
    Normal equations XᵀXβ̂ = Xᵀy
    Closed form      β̂ = (XᵀX)⁻¹Xᵀy
    SLR              m = S_xy/S_xx = Cov(x,y)/Var(x),   c = ȳ - m·x̄
    Gradient         ∇J(β) = (1/n)Xᵀ(Xβ - y)
    Hessian          ∇²SSE = 2XᵀX   (PSD, so SSE is convex)
    Projection       ŷ = Hy,  H = X(XᵀX)⁻¹Xᵀ
    Decomposition    TSS = ESS + RSS
    Ridge            β̂ = (XᵀX + λI)⁻¹Xᵀy
    Unbiasedness     E[β̂] = β
    Variance         Cov(β̂) = σ²(XᵀX)⁻¹
    Noise estimate   σ̂² = RSS/(n - d - 1)


PART 1 — THE OBJECTIVE: WHY SQUARED ERROR
==============================================================================

Before we can find the best line we have to decide what "best" means. Any
candidate β makes n mistakes at once,

    eᵢ = yᵢ - xᵢᵀβ

and we cannot minimize n numbers, so they have to collapse into one score.

First attempt: add them. Σeᵢ. Dead on arrival — a line that misses by +100 and
by -100 scores a perfect zero. Cancellation means the score has to be blind to
the SIGN of a mistake, and there are two natural ways to blind it: |e| and e².

They are both legitimate, and they quietly answer different questions.

    |e|   every point pulls on the line with the same force no matter how
          wrong it is (d|e|/de = ±1). Robust, and it lands on the conditional
          MEDIAN. 
          Price: no derivative at 0, so no closed form — you iterate.

    e²    the pull grows with the mistake (de²/de = 2e), so a point twice as
          far away pulls twice as hard and gets prioritized.

Choosing e² is what makes the rest of this file possible:

1. It is SOLVABLE. e² is smooth and convex, so setting ∇ = 0 gives a linear
   system with an exact answer (PART 3). This is the reason linear regression
   has a formula at all when almost nothing else does.

2. It is the HONEST choice if the noise is Gaussian — i.e. it is the MLE. With
   ε ~ N(0, σ²I):

       L(β)     = Πᵢ (1/√(2πσ²))·exp( -(yᵢ - xᵢᵀβ)²/(2σ²) )
       log L(β) = -(n/2)log(2πσ²) - (1/(2σ²))·Σᵢ(yᵢ - xᵢᵀβ)²

   Only the last term involves β, so maximizing likelihood IS minimizing
   Σeᵢ². Squared error was never a convention — it is an assumption about the
   noise. Swap in Laplace noise and the same argument hands you MAE.

3. It answers the question "what is the average y around here?". The minimizer
   of E[(y - f(x))²] over all functions f is f(x) = E[y|x], the conditional
   mean.

So the objective, and its cosmetic variants:

    SSE(β) = Σᵢ (yᵢ - xᵢᵀβ)² = ||y - Xβ||²
    MSE(β) = (1/n)·SSE(β)
    J(β)   = (1/(2n))·SSE(β)     the ½ pre-cancels the 2 from differentiating

The 1/n and the ½ do not move the minimizer — only the scale of the gradient,
and hence the learning rate you need.

Now the bill. Because the pull grows with distance, a point 10× further out
contributes 100× the error and drags the line toward itself. OLS is not robust
to outliers, and that is not a flaw to be patched: it is the same property that
bought us the closed form and the conditional mean. If you need robustness you
have to give one of those up — Huber (quadratic near 0, linear in the tails),
quantile regression, or RANSAC.


PART 2 — SLR CLOSED FORM
==============================================================================

PART 1 settled the score. Now the easiest possible case — one feature, two
knobs — and we cash in the promise that squaring buys an exact answer:

    ŷᵢ = m·xᵢ + c        SSE(m, c) = Σ(yᵢ - m·xᵢ - c)²

SSE is quadratic in (m, c), so its surface is a bowl. A bowl has exactly one
flat spot and it is the bottom, which is the whole reason we can just solve for
it instead of walking downhill: find where the surface is flat in both
directions and you are done. Two knobs, so two equations.

    ∂SSE/∂c = -2 Σ (yᵢ - m·xᵢ - c)  = 0
    ∂SSE/∂m = -2 Σ xᵢ(yᵢ - m·xᵢ - c) = 0

These are the normal equations, and each one is a readable statement about the
residuals eᵢ rather than a piece of algebra:

    (1)  Σeᵢ    = 0      the line sits level with the data — as much above as
                         below. Rearranged:  Σyᵢ = m Σxᵢ + n·c
    (2)  Σxᵢeᵢ  = 0      no leftover relationship between x and what is left
                         over. If there were, tilting the line would still be
                         earning something. Rearranged:  Σxᵢyᵢ = m Σxᵢ² + c Σxᵢ

Condition (2) is orthogonality, and it is the seed of the projection picture in
PART 4: the fit extracts everything about y that x can explain, and the
residual keeps only what x knows nothing about.

Step 1 — divide (1) by n:

    ȳ = m·x̄ + c     ⇒     c = ȳ - m·x̄

Read what just happened: the intercept is not really a free parameter. Once the
slope is chosen, c only slides the line up or down to pass through the centroid
(x̄, ȳ). Every least-squares line with an intercept goes through the mean point.

Corollary worth stating loudly: since ∂SSE/∂c = 0 IS Σeᵢ = 0, residuals of an
intercept-containing fit sum to zero by construction. "Residuals have mean
zero" is an algebraic identity, not a testable assumption. What you actually
test is zero mean CONDITIONAL on x — i.e. no pattern in the residual plot.

Step 2 — substitute c into (2) to eliminate it and leave m alone:

    Σxᵢyᵢ = m Σxᵢ² + (ȳ - m·x̄)Σxᵢ
          = m Σxᵢ² + n·x̄·ȳ - m·n·x̄²          using Σxᵢ = n·x̄

    Σxᵢyᵢ - n·x̄·ȳ = m(Σxᵢ² - n·x̄²)

Both sides turn out to be centered sums — the raw sums minus what you would
expect from the means alone:

    S_xy = Σ(xᵢ - x̄)(yᵢ - ȳ) = Σxᵢyᵢ - n·x̄·ȳ
    S_xx = Σ(xᵢ - x̄)²        = Σxᵢ²  - n·x̄²

    (proof of the second: Σ(xᵢ-x̄)² = Σxᵢ² - 2x̄Σxᵢ + n·x̄²
                                    = Σxᵢ² - 2n·x̄² + n·x̄² = Σxᵢ² - n·x̄²)

Therefore:

    ┌────────────────────────────────────────────┐
    │  m = S_xy/S_xx = Cov(x,y)/Var(x)           │
    │  c = ȳ - m·x̄                               │
    └────────────────────────────────────────────┘

The slope has a sentence attached to it: how much x and y move TOGETHER,
divided by how much x moves on its own. The numerator is the signal, and the
denominator is the price — if x barely varies, the same covariance has to be
explained by a much steeper line, and the estimate gets unstable. That single
ratio is where multicollinearity, low-variance features and large standard
errors all come from later.

Three equivalent readings, each useful somewhere else:

    m = Cov(x,y)/Var(x)                  covariance scaled by input spread
      = r_xy·(s_y/s_x)                   correlation rescaled into y-units;
                                         |r| ≤ 1 is why the fitted line is
                                         always flatter than the data's own
                                         spread — regression to the mean
      = Σwᵢyᵢ,  wᵢ = (xᵢ - x̄)/S_xx       a weighted average of the y's, so β̂ is
                                         LINEAR in y (this form makes PART 8's
                                         unbiasedness and variance immediate)

Degenerate case: S_xx = 0 means x is constant, so the slope is 0/0. Sensible —
a vertical strip of points supports infinitely many lines equally well, and
there is nothing to divide the covariance by. Hence the np.isclose guard in the
code rather than a crash.

Second-order check, to confirm the bowl is genuinely a bowl:

    H = 2·[ Σxᵢ²  Σxᵢ ]      det(H) = 4(nΣxᵢ² - (Σxᵢ)²) = 4n·S_xx ≥ 0
          [ Σxᵢ    n  ]      trace(H) > 0

so H is PSD, and positive definite whenever S_xx > 0. Note the determinant is
n·S_xx again: the same quantity that has to be non-zero for the slope to exist
is the one that has to be non-zero for the minimum to be unique. Stationary
point ⇒ global minimum.


PART 3 — MLR CLOSED FORM
==============================================================================

Expand the objective:

    SSE(β) = (y - Xβ)ᵀ(y - Xβ)
           = yᵀy - yᵀXβ - βᵀXᵀy + βᵀXᵀXβ
           = yᵀy - 2βᵀXᵀy + βᵀXᵀXβ

The middle terms combine because yᵀXβ is 1×1, so it equals its transpose βᵀXᵀy.

Matrix calculus used:

    ∂(aᵀβ)/∂β  = a
    ∂(βᵀAβ)/∂β = 2Aβ     for symmetric A (XᵀX always is)

Gradient, set to zero:

    ∇SSE(β) = -2Xᵀy + 2XᵀXβ = 0

    ┌──────────────────────┐
    │   XᵀXβ̂ = Xᵀy         │   ← the normal equations; memorize this form
    └──────────────────────┘

    ┌──────────────────────┐
    │   β̂ = (XᵀX)⁻¹Xᵀy     │   ← only when XᵀX is invertible
    └──────────────────────┘

Check that this contains Part 2. At d = 1 with an intercept column:

    XᵀX = [ n     Σxᵢ  ]     Xᵀy = [ Σyᵢ   ]
          [ Σxᵢ   Σxᵢ² ]           [ Σxᵢyᵢ ]

Inverting the 2×2 and multiplying out reproduces m = S_xy/S_xx and c = ȳ - m·x̄.
SLR is not a separate algorithm.

Convexity:

    ∇²SSE(β) = 2XᵀX,    and for any v:  vᵀ(XᵀX)v = ||Xv||² ≥ 0

So XᵀX is always PSD and SSE is always convex — no local minima, ever. It is
STRICTLY convex (unique β̂) iff ||Xv||² > 0 for all v ≠ 0, i.e. iff X has full
column rank. That condition is Part 5.

Do not literally invert. (XᵀX)⁻¹ is notation, not an algorithm: forming XᵀX
squares the condition number of X, losing about twice the precision necessary.
In practice, solve instead:

    Cholesky on XᵀXβ = Xᵀy    fastest; needs XᵀX positive definite
    QR of X                   the standard workhorse; better conditioned
    SVD / pseudo-inverse      slowest, most robust; handles rank deficiency

np.linalg.lstsq and sklearn's LinearRegression both use an SVD path, which is
why they still return an answer on collinear data where np.linalg.inv(X.T @ X)
blows up. Use solve or lstsq, never inv.


PART 4 — GEOMETRY: OLS IS A PROJECTION
==============================================================================

The achievable predictions {Xβ} form the column space of X, a d-dimensional
subspace of ℝⁿ. y generally does not lie in it, so minimizing ||y - Xβ|| means
finding the closest point in col(X) to y — the orthogonal projection.

The residual must be perpendicular to that subspace:

    Xᵀ(y - Xβ̂) = 0     ⇔     XᵀXβ̂ = Xᵀy

So the normal equations ARE the statement "residual ⊥ every column of X" —
"normal" means perpendicular. OLS can be derived from this line alone, with no
calculus.

The hat matrix puts the hat on y:

    ŷ = Xβ̂ = X(XᵀX)⁻¹Xᵀy = Hy

    Hᵀ = H          symmetric
    H² = H          idempotent — projecting twice changes nothing
    trace(H) = d    number of fitted parameters (effective degrees of freedom)
    e = (I - H)y    (I - H) projects onto the orthogonal complement, so e ⊥ ŷ
    hᵢᵢ             leverage of point i: how far xᵢ sits from the centre of the
                    feature cloud (see Cook's distance in assumptions.txt)

Two consequences.

Sum-of-squares decomposition. Since e ⊥ ŷ, Pythagoras gives

    Σ(yᵢ - ȳ)² = Σ(ŷᵢ - ȳ)² + Σ(yᵢ - ŷᵢ)²
       TSS     =     ESS     +      RSS

R² = ESS/TSS = 1 - RSS/TSS follows immediately. Its "share of variance
explained" reading is valid ONLY because of this orthogonality, which is why it
requires an intercept.

Adding a feature can never increase training RSS. A new column enlarges col(X),
and distance to a larger subspace cannot grow. So training R² is monotone
non-decreasing in d, even for a column of pure noise — hence adjusted R², and
hence training R² is useless for model selection.


PART 5 — WHEN XᵀX IS SINGULAR
==============================================================================

XᵀX invertible ⇔ X has full column rank ⇔ no feature is an exact linear
combination of the others. It fails when:

  1. d > n. rank(X) ≤ n < d, so XᵀX is always singular and infinitely many β
     achieve zero training error. The fit is not identified.
  2. Exact collinearity — duplicated columns, the same feature in two units, or
     the dummy trap (all k one-hot levels plus an intercept).
  3. A constant column other than the intercept.

Near-singular is the common case: strongly but not perfectly correlated
features. XᵀX is technically invertible but badly conditioned, and the damage
appears in the per-coefficient variance from Part 8:

    Var(β̂ⱼ) = σ² / ( S_jj·(1 - R²ⱼ) )      R²ⱼ = R² of xⱼ regressed on the
                                            other features
    VIFⱼ = 1/(1 - R²ⱼ)

As R²ⱼ → 1, Var(β̂ⱼ) explodes. The key structural point: this inflates the
variance of INDIVIDUAL COEFFICIENTS but leaves PREDICTIONS intact, because ŷ is
the projection onto col(X) and does not depend on how that space is
parameterized. Symptoms and worked examples: MLR/concept.txt section 6.

Fixes, in rough order of preference: drop or merge redundant features (highest
VIF first, refit, repeat); ridge (Part 7), which makes XᵀX + λI invertible by
construction; PCA/PLS on the correlated block; the pseudo-inverse β̂ = X⁺y,
which returns the minimum-norm solution among all least-squares solutions (what
lstsq does); or collect more data.


PART 6 — GRADIENT DESCENT
==============================================================================

    J(β)  = (1/(2n))||Xβ - y||²
    ∇J(β) = (1/n)Xᵀ(Xβ - y)
    β ← β - α·(1/n)Xᵀ(Xβ - y)

In scalar SLR form, with J = (1/n)Σ(yᵢ - m·xᵢ - c)²:

    ∂J/∂m = (-2/n)Σxᵢ(yᵢ - m·xᵢ - c)        m ← m - α·∂J/∂m
    ∂J/∂c = (-2/n)Σ(yᵢ - m·xᵢ - c)          c ← c - α·∂J/∂c

Update m and c SIMULTANEOUSLY from the same residual vector. Using the new m to
compute the c gradient is a different, wrong algorithm.

Convergence. J is convex with Hessian (1/n)XᵀX, so GD reaches the global optimum
for any fixed step size

    0 < α < 2/L,     L = λ_max((1/n)XᵀX)

and the rate depends on the condition number κ = λ_max/λ_min, with error
shrinking per step roughly like ((κ-1)/(κ+1))². Ill-conditioned means a long
narrow valley, so GD zig-zags and crawls.

This is why scaling matters for GD and not for OLS. With x₁ ∈ [0,1] and
x₂ ∈ [0,10⁶], κ is enormous: any α stable in the steep direction is far too small
for the flat one. Standardizing makes the contours near-circular. The closed form
solves the system outright rather than walking the surface, so it is exact at any
scaling. (With a penalty, scaling matters even in closed form — Part 7.)

Variants:
    Batch       full X per step; exact gradient, slow per step
    SGD         one sample per step; noisy, cheap, needs a decaying α; the noise
                is a mild regularizer
    Mini-batch  the practical default (32-512)
    Momentum / Adam   rescale the step per direction, which is how modern
                      optimizers survive bad conditioning

Why learn it at all, given the closed form exists: no closed form exists for
Lasso, logistic regression, SVMs or neural nets. Gradient methods are the one
optimizer that transfers to all of them.

Diverging loss (inf or NaN) means α is too large, usually because features were
not scaled. For batch GD, J must decrease monotonically — if it does not, the
learning rate is wrong, not the model.


PART 7 — RIDGE AND LASSO
==============================================================================

Ridge (L2):

    J(β) = ||y - Xβ||² + λ||β||²
    ∇J   = -2Xᵀ(y - Xβ) + 2λβ = 0

    ┌───────────────────────────────┐
    │  β̂_ridge = (XᵀX + λI)⁻¹Xᵀy    │
    └───────────────────────────────┘

XᵀX is PSD, so XᵀX + λI has eigenvalues (λᵢ + λ) > 0 for any λ > 0: always
positive definite, hence always invertible. Ridge dissolves the singularity of
Part 5 by construction. In SVD terms with X = UΣVᵀ, it shrinks each singular
direction by σⱼ²/(σⱼ² + λ), so the smallest σⱼ — the unstable directions — are
damped hardest.

Do not penalize the intercept, and standardize first: ||β||² is not
scale-invariant, so unscaled features receive arbitrarily unequal penalties.

Lasso (L1):

    J(β) = ||y - Xβ||² + λ||β||₁

|β| is not differentiable at 0, so there is no closed form — solved by
coordinate descent, LARS, or proximal methods. The L1 constraint region has
corners on the axes, so the optimum often lands exactly on one, giving sparsity
and thus feature selection. Ridge shrinks smoothly and essentially never to
exactly zero. Elastic Net uses both penalties, keeping sparsity while handling
correlated groups better than pure Lasso.

Both trade bias for variance: λ > 0 biases the estimate but reduces variance, so
they beat OLS in test MSE whenever variance dominates the error — small n, large
d, collinear features. This is the boundary of Gauss-Markov optimality (Part 8):
BLUE ranks only UNBIASED estimators, and ridge deliberately leaves that class.
See ../../regularization_concept.txt.


PART 8 — PROPERTIES OF β̂
==============================================================================

Assume y = Xβ + ε, E[ε] = 0, Cov(ε) = σ²I, X fixed and full rank.

Unbiasedness:

    β̂ = (XᵀX)⁻¹Xᵀ(Xβ + ε) = β + (XᵀX)⁻¹Xᵀε
    E[β̂] = β + (XᵀX)⁻¹Xᵀ·E[ε] = β

This needs only E[ε] = 0 — not normality, not constant variance. So
heteroscedastic or autocorrelated errors leave β̂ UNBIASED; they break the
STANDARD ERRORS. That is why the standard fix is robust (Huber-White) standard
errors rather than a different model.

Variance:

    Cov(β̂) = (XᵀX)⁻¹Xᵀ·Cov(ε)·X(XᵀX)⁻¹ = σ²(XᵀX)⁻¹

    Var(β̂ⱼ) = σ² / ( S_jj·(1 - R²ⱼ) )

Three levers on precision: noise σ² hurts, spread S_jj (which grows with n)
helps, collinearity R²ⱼ hurts. In SLR:

    Var(m̂) = σ²/S_xx        Var(ĉ) = σ²(1/n + x̄²/S_xx)

Estimating the noise:

    σ̂² = RSS/(n - d - 1)

Divide by degrees of freedom, not n: d+1 were spent fitting parameters
(equivalently trace(H) = d+1), and dividing by n is biased downward.

Gauss-Markov. Under linearity, exogeneity, homoscedasticity and no
autocorrelation, OLS is BLUE — Best (minimum-variance) Linear Unbiased
Estimator. Every qualifier matters:
    - LINEAR — only among estimators linear in y; nonlinear ones can beat it.
    - UNBIASED — only among unbiased ones; ridge is biased and often has lower
      MSE.
    - Normality is NOT required. It buys exact t and F distributions for small
      samples; at large n the CLT gives those approximately anyway.

With normality, β̂ ~ N(β, σ²(XᵀX)⁻¹), giving

    tⱼ = β̂ⱼ/SE(β̂ⱼ) ~ t_(n-d-1)      per-coefficient test
    F-test                            whole model / nested comparison

Significance of a coefficient always depends on which other features are in the
model.


PART 9 — COMPUTATIONAL COST
==============================================================================

    Method            Time                  Notes
    ----------------  --------------------  ------------------------------
    Normal eq (inv)   O(nd² + d³)           exact; unstable; avoid
    Cholesky solve    O(nd² + d³/3)         exact; needs XᵀX pos. def.
    QR                O(nd²)                exact; standard workhorse
    SVD / pinv        O(nd²), larger const  exact; handles rank deficiency
    Batch GD          O(nd) per iteration   needs scaling and α tuning
    SGD / mini-batch  O(d) per sample       streams data; online updates

Choosing:
    - d up to a few thousand, X fits in memory → closed form via QR/SVD (lstsq).
      Exact, one shot, no hyperparameters.
    - d very large, n huge, or streaming → mini-batch SGD.
    - Rank-deficient or heavily collinear → ridge, or pinv for minimum-norm.
    - Need L1 sparsity → coordinate descent; no closed form exists.
    - Very different feature scales with any iterative method or any penalty →
      standardize first.
