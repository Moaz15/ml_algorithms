1. WHAT IS FEATURE IMPORTANCE?
--------------------------------------------------------------------------------
Feature importance measures how much each feature contributes to reducing 
impurity (or error) across all splits in a tree. It provides an intuitive, 
interpretable way to understand what data signals the model relies on most.


2. HOW IT'S CALCULATED: MEAN DECREASE IN IMPURITY (MDI)
--------------------------------------------------------------------------------
At each internal node, the tree uses a single feature to split the data. The 
importance of that feature accumulates credit based on the impurity reduction 
it achieves, weighted by the fraction of samples it affects.

For each node (t) that splits on feature (f):

  Importance(f) += (N_t / N) * (Impurity_t - w_left*Impurity_left 
                                           - w_right*Impurity_right)

Where:
* N_t / N          = Fraction of total samples reaching node t.
* w_left / w_right = Fraction of samples sent to each child node.
* Impurity         = Gini index/Entropy (Classification) or MSE/MAE (Regression).

Normalization:
The raw values for all features are summed up at the end, and each feature's 
score is divided by the total sum so that all feature importances sum to 1.0 (100%).


3. INTUITION & INTERPRETATION
--------------------------------------------------------------------------------
* High Importance: Feature appears near the root, splits many samples, and 
                   causes a massive drop in impurity.
* Low Importance : Feature appears deep in the tree or is rarely chosen.
* Zero Importance: Feature was never chosen for any split.


4. THE PROS AND CONS OF MDI
--------------------------------------------------------------------------------
Pros:
* Fast to Compute: Calculated automatically during training; comes "for free".
* Model-Intrinsic: Requires no extra post-processing data or baseline models.
* Nonlinear: Naturally captures complex feature interactions without manual adjustments.

Cons:
* High-Cardinality Bias: Heavily inflated for continuous variables or categories 
  with many unique values (e.g., IDs, Zip Codes). Because they offer more split 
  points, the greedy algorithm naturally prefers them, even if they are noise.
* Training Set Bias: MDI is computed purely on training data. If a tree overfits, 
  MDI will confidently rank noisy, overfitted features as "highly important".
* The Correlation Trap: If two features are highly correlated, the tree will 
  arbitrarily pick one for an early split. The chosen feature gets high 
  importance, while the other looks completely useless, masking its true utility.
* Directionless: Tells you *that* a feature matters, but not *how* (doesn't 
  distinguish between positive and negative effects).


5. COMPLEMENTARY METRIC: PERMUTATION IMPORTANCE (MDA)
--------------------------------------------------------------------------------
To fix the flaws of MDI, Mean Decrease in Accuracy (MDA) is used:
1. Train the tree normally.
2. Shuffle/scramble the values of a single feature column in the test/validation set.
3. Pass the altered data through the tree and measure the drop in accuracy/score.
4. Large drop = High importance. Small/No drop = Low importance.

Advantages over MDI:
* Can be evaluated on an independent test set (reflects true generalization power).
* Unbiased against high-cardinality features.


6. SUMMARY: WHEN TO USE WHAT
--------------------------------------------------------------------------------

| Method                 | Best For                       | Major Limitation        |
|------------------------|--------------------------------|-------------------------|
| Gini / MDI Importance  | Quick exploratory overview;    | Biased by cardinality,  |
|                        | low-cardinality features.       | overfits training noise.|
|------------------------|--------------------------------|-------------------------|
| Permutation Importance | Unbiased post-training testing;| Computationally slower; |
|                        | accurate feature selection.     | hurt by correlations.   |
|------------------------|--------------------------------|-------------------------|
| SHAP Values            | Explaining *why* for single     | Highly compute-intensive|
|                        | samples; positive/negative direction.                     |


PRACTICAL TAKEAWAY:
Never rely solely on default MDI (Gini) importance for feature selection. Always 
cross-validate the feature ranking by computing Permutation Importance on an 
independent validation set to avoid keeping overfitted noise features.
